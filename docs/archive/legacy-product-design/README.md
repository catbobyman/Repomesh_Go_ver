## 打开原型

双击 [产品原型/index.html](产品原型/index.html)。无需安装，也无需启动任何服务。

统一原型沿用原产品的需求中心布局、暖黑与琥珀配色、奶油色计划纸面；使用明确标识的演示数据，主要流程可点击。所有操作只改变当前页面的演示状态，刷新恢复初始场景；不会连接真实仓库、账号、模型或本机智能体。

原有网页原型的完整副本另存于 [产品原型/历史原型](产品原型/历史原型)，从统一原型的“阅读指引”可直接打开。它们用于对照历史设计，不代表现行完整功能。

## 范围标识

- **保留**：在当前产品界面或业务能力中有依据，重写需覆盖；不等于本次完成了真实环境验收。
- **补齐**：已有明确需求或部分能力，但完整用户流程、界面或外部接入仍存在缺口。
- **扩展**：现有材料中的未来方案，单列保留，不能视作当前已可用功能。

这些标识描述依据成熟度，不是删减功能的优先级。完整范围是三者的并集，首版选择须单独评审。

为保持 PRD 的产品口径，整理依据、历史冲突及原型检查记录单独放在 [整理记录](整理记录/依据与范围核对.md)，不属于 PRD 正文。
