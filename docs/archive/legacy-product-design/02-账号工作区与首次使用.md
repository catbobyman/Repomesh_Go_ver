# 02 · 账号、工作区与首次使用

## 目标与范围

让首次使用者完成必要准备，也让日常用户安全返回自己的工作区。本册除另行标注外均为保留功能。

## 功能需求

| 编号 | 功能 | 操作与结果 |
| --- | --- | --- |
| ACC-01 | 首位管理员初始化 | 首次进入可创建首位管理员，填写用户名、显示名称、密码；完成后进入配置。管理员已存在时关闭初始化入口并提示登录 |
| ACC-02 | 登录与退出 | 以用户名和密码登录；显示身份与管理员标记；退出后需要重新登录才能处理受保护事项 |
| ACC-03 | 本地账户管理 | 管理员查看账户列表、创建普通审核人或管理员；普通用户无法管理他人账户 |
| ACC-04 | 工作区创建与切换 | 命名新工作区，为其登记组织负责人；切换后需求、仓库与操作上下文同步改变，明显显示当前工作区 |
| ACC-05 | 角色与范围授权 | 为用户授予组织、项目或仓库监督职责，指定资源范围、查看与修改权限、允许的控制动作；授权与账户分别管理 |
| SET-01 | 首次配置向导 | 按平台检测、模型连接、仓库托管服务授权、管理员状态、仓库与团队五步推进；每步说明当前结果和下一步 |
| SET-02 | 模型连接 | 填写服务地址、模型名称与访问凭证，保存并检测；显示是否配置、脱敏摘要和最近更新时间 |
| SET-03 | 仓库托管服务连接 | 管理员配置仓库服务应用及其授权材料；检查连接是否足以扫描、执行和交付，区分可选与必需条件 |
| SET-04 | 自动准备进度 | 展示排队、准备中、等待用户、可重试失败、需检查环境、完成；显示实际阶段和最近更新时间 |
| SET-05 | 失败重试与继续 | 自动准备失败后保留成功步骤；允许按提示补齐配置并重试；离开后返回可继续观察 |
| SET-06 | 设置总览 | 查看各服务连接、执行能力、模型连接、已登记智能体工具、配置完整性和就绪状态；管理员可回到配置向导 |

## 输入与校验

- 用户名不可为空或重复；密码至少 12 位；创建失败保留已填的非敏感内容。
- 密码与外部凭证不出现在列表、通知、共享资料或历史证据中；已保存凭证只显示脱敏状态。
- 工作区名称必填；同一创建操作重试应返回同一工作区。
- 工作区创建成功不表示团队已可执行，需继续检查仓库和运行准备。
- 所有管理操作以当前登录人为操作人，不能通过填写他人名称冒用身份。

## 首次使用状态

| 状态 | 页面行为 |
| --- | --- |
| 正在验证身份 | 显示等待，不提前展示受保护内容 |
| 未登录 | 显示登录；符合首次使用条件时提供初始化 |
| 身份服务不可用 | 说明无法校验身份，提供刷新；不伪装为密码错误 |
| 已登录但配置不足 | 管理员进入向导；普通用户看到需要管理员处理的说明 |
| 基础配置完成 | 可以进入工作台；每个需求开工时仍单独检查实际所需能力 |
| 会话过期 | 提示重新登录；未提交的非敏感内容尽可能保留 |

## 权限细则

账户管理员负责账户与平台连接；项目监督人负责获准项目；仓库监督人只处理其仓库。允许浏览工作台不代表能批任何需求。多工作区汇总只能包含当前用户获准的数据，汇总计数与列表必须采用同一范围。

## 补齐与扩展

ACC-06 为补齐功能：账户停用、密码恢复、会话管理及异常登录保护。ACC-07 为扩展功能：企业统一登录。它们在已有材料中被列为后续完善项，不能用原型里的演示登录证明已具备真实身份能力。

## 验收

1. 新环境只允许成功初始化一次管理员，第二次操作进入明确的已有账户提示。
2. 管理员创建审核人后，审核人可登录，但不能管理账户或查看未授权需求。
3. 退出或会话过期后，原审批页面不能继续提交决定。
4. 配置失败可看到原因与恢复动作，返回向导时保留已完成步骤。
5. 切换工作区后，列表、计数、详情和新增需求归属一致。
