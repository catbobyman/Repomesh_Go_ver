# 04 · 需求、规格与计划

## 需求管理

| 编号 | 功能 | 用户操作与结果 |
| --- | --- | --- |
| REQ-01 | 新建需求 | 在当前工作区描述目标，显示负责接收的组织负责人；成功后进入需求详情，重复提交不重复创建 |
| REQ-02 | 需求文档导入 | 支持文本、Markdown、Word、PDF、ODT、RTF 文档；展示文件名、解析字符数和截断提示，支持移除文档再手填 |
| REQ-03 | 草稿保护 | 关闭新建弹窗后保留本次草稿；创建失败保留内容，创建成功后清空 |
| REQ-04 | 需求列表 | 采用未结束与已结束两个页签，行内展示标题、当前阶段、暂停或待决策标记、仓库数、轮次数；支持续页查看 |
| REQ-05 | 需求详情 | 显示原始需求、来源文档、发起时间、规格版本、关联仓库与团队、发现流程、监管、计划、房间、决策与交付轮次 |
| REQ-06 | 澄清与继续 | 对信息不足的需求逐题补充后重新分析；允许显式忽略追问继续，但必须记录忽略数量及决定 |
| REQ-07 | 需求检索与筛选 | 按标题、阶段、仓库及待办状态筛选，显示同范围计数和空结果；完整组合筛选属于补齐项 |

REQ-01 至 REQ-06 为保留功能。输入方式应清楚标识：已导入文档时以该文档作为需求来源，不能悄悄与原有手填内容混合。文件格式不支持、体积过大、无可解析正文、内容截断分别提示。

## 规格功能

| 编号 | 功能 | 规则 |
| --- | --- | --- |
| SPC-01 | 分层规格 | 将确认后的需求转为项目目标、跨仓协作约定、各仓职责和任务说明，包含目标、非目标、约束、依赖、验收标准和交付要求 |
| SPC-02 | 规格评审与冻结 | 规格经历草稿、待审、批准或冻结；被采用的版本可追溯，后续修订保留旧版本 |
| SPC-03 | 当前任务说明 | 执行成员只得到当前任务需要的目标、约束、验收条件和获准参考资料；完整项目资料不会无差别分发 |

规格能力为保留，独立规格编写与版本比较的完整用户界面为补齐。

## 计划功能

| 编号 | 功能 | 规则与结果 |
| --- | --- | --- |
| PLN-01 | 集成计划生成 | 根据已确认范围生成各仓工作、依赖、批次、跨仓提供与使用关系及风险；显示计划版本和生成依据 |
| PLN-02 | 依赖图与计划纸面 | 按批次分列展示，明确谁先谁后、哪些能并行；可查看节点职责、状态和依赖理由；待确认节点保持可见 |
| PLN-03 | 开工预览 | 展示当前计划版本、仓库清单、任务数、团队与成员、执行模式、监管摘要及就绪检查；用户确认后正式开工 |
| PLN-04 | 执行进度 | 按任务、仓库与批次展示待执行、执行中、修复中、阻塞、失败、完成；查看当前批次及下游等待原因 |
| PLN-05 | 局部重新规划 | 上游结果或范围变化后重新评估受影响工作，说明保留、替代和新增项，产生新计划及交付轮次 |
| PLN-06 | 增量追加工作 | 在运行计划上预览新增仓库工作与依赖，确认后保留修订记录；不能修改已开始或已完成的工作 |
| PLN-07 | 正式变更请求 | 对目标、范围、验收、协作约定或权限变化提出请求，展示影响、风险及重做范围，经批准、拒绝或重规划后执行 |

PLN-01 至 PLN-05 为保留；PLN-06 为补齐，已有明确受限能力；PLN-07 为补齐，现有材料把完整变更治理列为待完善功能。

## 计划约束

- 计划图只读。改变范围通过调整分档后重新生成，不能直接拖动依赖或随意改变已冻结批次。
- 缺失依赖、循环关系、自我依赖、重复仓库、将新任务放在已开工工作之前，均不能通过检查。
- 增量追加首期只用于计划中尚未出现的仓库；已有仓库的新工作采用重新规划。
- 增加未授权仓库必须先完成范围审批；预览不会派工。
- 当前批次已经执行时，新工作最早进入后续批次；已完成部分及其历史不改写。
- 已完成或失败的计划不能继续追加，需新一轮或重规划。
- 新计划必须说明哪些既有验证仍有效，不能默认所有旧结论都适用。

## 开工门槛

需求、范围与计划版本有效；必需仓库可访问；组织负责人及仓库团队关系完整；实际执行成员和独立验证能力就绪；监管策略及审核人授权有效。任一条件不满足，应停在可理解的预览页并提供处理入口。

## 验收

1. 手填和文档导入都能形成需求，文件删除后恢复手填入口。
2. 澄清不足时不能伪装分析完成；忽略追问能在历史中查到。
3. 计划中的仓库与已确认范围相符；有依赖的仓库按顺序安排。
4. 预览不会产生执行，重复确认只产生一轮开工。
5. 追加工作保留已完成任务；非法依赖明确拒绝；修改旧工作进入重规划。
6. 需求暂停、计划更新或证据过期后，旧开工页面不能继续使用原确认。
