# 产品网页原型

双击本目录的 [index.html](index.html) 即可打开。请一起保留 `index.html`、`styles.css`、`app.js` 和“历史原型”目录。

本原型不需要安装依赖，不需要网络，不需要启动原项目。已用 Chrome 验证本地文件直接打开。

- 默认进入 Commerce 演示工作区；可切换至 Internal 查看空态。
- 需求 #42：执行过程；#41：人工审核及数据验证外部阻塞；#40：已交付（在“已结束”中）；#39：执行异常；#38：开工预览。
- 完整流程可从“新建需求”开始。需在“执行与房间”点击推进按钮模拟执行、初审与复验，再到审核台批准，最后回需求确认交付。
- 可在需求概览切换演示阶段；刷新页面恢复初始记录。
- “设置”内有首次配置、账户、技能与运营管理；“阅读指引”可打开四份原有网页原型。

演示不会验证真实身份、访问仓库、调用模型、启动成员、执行测试、发通知或发布交付。只有导入文本与导出演示摘要会读取用户所选文件或生成本地下载。请勿输入真实凭证。

原型用于确认页面与交互，完整产品要求以本目录上一级的 14 份 PRD 为准。
